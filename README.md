# Assignment Management System - Backend

A scalable backend API for an assignment management platform built with **Node.js, Express.js, and MongoDB**.

The system supports multiple frontend websites using a single backend instance. Each website is identified using a unique **website tag**, allowing separate pricing rules, users, orders, and business configurations while sharing the same infrastructure.

---

# 🚀 Features

## Authentication System

- Student registration
- User login
- JWT-based authentication
- Role-based authorization
- Current user profile retrieval
- Email availability checking

Supported roles:

- Student
- Admin
- Sales Agent
- Writer
- Writer Manager
